CSV Format

Use this exact header row. Each product must reference an existing category id.

name,description,category_id,price,brand,quantity

Requirements

  • The file must be UTF-8 encoded.
  • The header row is required.
  • quantity must be an integer.
  • price must be a valid number.
  • category_id must already exist.
